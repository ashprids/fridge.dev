*[frontend]: Anything that the visitors of your website can see
*[HTML]: Hypertext Markup Language: The code that defines the structure and layout of content
*[CSS]: Cascading Stylesheet: The code that defines what your website looks like visually
*[JavaScript]: A programming language used to add interactive features to a website
*[JS]: JavaScript: A programming language used to add interactive features to a website
*[PHP]: A programming language used to develop dynamic web applications
*[GitHub Pages]: A platform developed by Microsoft for hosting static websites for free
*[custom hosting]: We'll need to set up a dedicated server for running the website properly
*[metric tracking]: Keeping track of user statistics (e.g. how many views a page has)
*[input validation]: Ensuring people cannot put invalid data into forms (e.g. letters where you'd only expect numbers)
*[anti-injection]: Ensuring people cannot run code on the server (i.e. by typing it into a text box)
*[landing pages]: A single web page reached after clicking on an ad or social media link (LinkTree would be an example of this)
*[dynamic]: When the contents of a website frequently change (i.e. through user uploads)
*[domain]: The URL used to access your website (e.g. https://google.com)
*[SEO]: Search Engine Optimization: Ensuring that your website is optimized for appearing on search engines

## What I'm offering

I typically split the different websites I make into three categories, which you can see in the table
below. These are not strict guidelines, however, as every project has its own needs, and I can be very
flexible.

> I'm going to use a lot of terminology on this page. If you don't know what anything means, you can
> tap on/hover over the words with dotted lines to show a definition.


> [!note]
> Don't worry if you're not entirely sure what you need yet! We can discuss this further once you've
> reached out.

| basic | plus | pro |
| --- | --- | --- |
| simple static website (HTML, CSS, JavaScript) | simple PHP-based website (same as basic, including PHP) | advanced PHP-based website (same as plus, including database) |
| free hosting via GitHub Pages | custom hosting required | custom hosting required |
| must update content manually via HTML editing | content updates/uploads via a password-protected admin page | content updates/uploads via role-based user accounts |
| basic UI features (e.g. theme switching, simple JS) | dynamic features (e.g. updating image galleries, content feeds, uploads) | advanced features (e.g. user accounts, social elements i.e. comments and likes, metric tracking) |
| basic security for inputs and forms (e.g. input validation, anti-spambot measures) | enhanced JS and PHP security (anti-injection, validation, etc.) | security tailored to whichever features you desire |
| best for simple personal sites, portfolios, landing pages | best for dynamic content-driven sites (galleries, blogs, news feeds) | best for complex, feature-rich applications (small social networks, communities, full applications) |
